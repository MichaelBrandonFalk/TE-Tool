Notes

  • Current release: A11.5.
  • Release packages should not be replaced in place; each package update gets a new GitHub release tag.
  • macOS may ask for Apple Command Line Tools; the app checks for them on launch.
  • Older packages can be downloaded from the release archive if a current build needs to be rolled back.
  • These builds are not notarized, so macOS may require approving the app in Privacy & Security after first launch.
