Important Implementation Notes

The script defines Broadcast Master targets of ProRes 4444, 200 Mb/s minimum, 29.97 fps, and 16:9 near the top of the file. The current Phase 1 codec and video bit rate functions do not use those variables. They currently enforce ProRes 422 HQ (apch) and 145 Mb/s minimum for both SVOD and Broadcast Master.

  • File extension checks are case-sensitive. .mov passes; .MOV does not.
  • Several checks return warnings instead of failures when the value is measurable but outside the preferred range.
  • Video aspect, position, and scale are listed by the app as a manual test and are not automatically evaluated.

Phase 1 Media Checks

Field Acceptable Value or Range Applies To Failure / Warning Behavior
File type Extension must be exactly mov. SVOD, Broadcast Master Any other extension fails.
Video codec codec_tag_string must be apch, reported as ProRes 422 HQ. SVOD, Broadcast Master Any other codec tag fails. Current code does not accept ProRes 4444 for Broadcast Master.
Video bit rate Must be a numeric stream bit rate greater than or equal to 145000000 bits/s, or 145.0 Mb/s. SVOD, Broadcast Master Lower values fail. Missing or non-numeric bit rate fails. Current code does not enforce the declared 200 Mb/s Broadcast Master target.
Resolution Exactly 1920x1080. SVOD, Broadcast Master Any other width or height fails.
Aspect ratio display_aspect_ratio must be 16:9. If metadata is unavailable, calculated width/height must be greater than 1.76 and less than 1.79. SVOD, Broadcast Master Anything not resolved to 16:9 fails.
Frame rate SVOD passes at 23.98. Broadcast Master passes at 29.97. Values are calculated from r_frame_rate and rounded to two decimals. SVOD, Broadcast Master SVOD at 29.97 returns a warning. All other mismatches fail.
Chroma sampling pix_fmt must start with yuv422. SVOD, Broadcast Master Any other pixel format fails.
Video scan type field_order must be progressive or Progressive. SVOD, Broadcast Master Interlaced or unknown scan type fails.
Audio codec codec_name must start with pcm. SVOD, Broadcast Master Any non-PCM audio codec fails.
Audio bit rate Expected bit rate is channels * 1152 Kb/s. Mono is 1152 Kb/s, stereo is 2304 Kb/s. SVOD, Broadcast Master The integer Kb/s value must match exactly. Missing or non-numeric bit rate fails.
Audio sample rate 48000 Hz, reported as 48 kHz. SVOD, Broadcast Master Any other sample rate fails.
Audio bit depth 24-bit PCM. The script checks bit depth metadata, format tags, sample format, and PCM codec name. SVOD, Broadcast Master Any resolved value other than 24 fails.
Timecode format Timecode must exist and contain ; or ,, indicating drop-frame format. Broadcast Master Phase 1 only Missing timecode or non-drop-frame timecode fails.
Video aspect / position / scale Manual review required. SVOD, Broadcast Master No automated pass/fail is implemented.

Phase 2 Checks

Field Acceptable Value or Range Applies To Failure / Warning Behavior
Head and tail dark frames First frame and last sampled frame must have YAVG less than or equal to the codec threshold: H.264/HEVC 45, ProRes/DNxHD 74, other codecs 40. SVOD Phase 2 Missing head, tail, or both fails.
Stereo only Exactly one audio stream and exactly two channels. SVOD Phase 2, Broadcast Master Phase 2 Any other stream count or channel count fails.
Dynamic stereo For stereo layout only, the loudest L-R RMS sample from 5-second windows at 0%, 25%, 50%, and 75% of runtime must be greater than -50 dB. SVOD Phase 2 Values less than or equal to -50 dB fail. Non-stereo layouts return N/A. Missing finite RMS returns an unable-to-test warning.
Loudness Integrated loudness from FFmpeg loudnorm input_i must be between -25 and -22 LUFS, inclusive. SVOD Phase 2, Broadcast Master Phase 2 Outside this range fails. Missing/invalid loudnorm JSON returns an unable-to-test warning.
Timecode start SVOD must start at 00:00:00:00 or 00:00:00;00. Broadcast Master must start at 00:58:30:00 or 00:58:30;00. SVOD Phase 2, Broadcast Master Phase 2 Missing or different start timecode fails and asks for Premiere adjustment.
Video markers ExifTool marker start time, name, and duration are read and reported. Broadcast Master Phase 2 Informational only; no pass/fail threshold is implemented.
Total run time Total video frame count is converted to 29.97-style drop-frame timecode. Broadcast Master Phase 2 Informational only; no acceptable duration range is implemented.
608 captions present At least one subtitle stream codec name must contain eia_608. Broadcast Master Phase 2 Missing 608 captions fail.
708 captions present At least one subtitle stream codec name must contain eia_708. Broadcast Master Phase 2 Missing 708 captions fail.

Optional and Advanced Checks

Field Acceptable Value or Range Applies To Failure / Warning Behavior
I-frame only Every video packet must be marked as a key packet, and the first 5000 decoded frames must not include P or B frames. SVOD, Broadcast Master Any non-I packet/frame fails.
Advanced continuity FPS must be detectable; FFmpeg decode must produce no errors; frame timestamp regressions must be none; timestamp gaps must be none for a clean pass. SVOD, Broadcast Master Decode errors or regressions fail. Gaps greater than 1.5 frame steps warn. Timestamp regression threshold is less than -0.0005 seconds.
Luma IRE Computed IRE must stay from -1 through 101, inclusive. Limited-range black/white code values are 16/235 for 8-bit, 64/940 for 10-bit, and 256/3760 for 12-bit. Full-range black/white values are 0/255, 0/1023, or 0/4095. SVOD, Broadcast Master Below -1 IRE or above 101 IRE returns a warning, not a failure. Standard Luma samples every 24 frames. Broadcast Master starts from the first 01:00:00:00 or 01:00:00;00 point if found within the script's search window.
Advanced Luma IRE Same IRE range as standard Luma, but samples every frame. SVOD, Broadcast Master Below -1 IRE or above 101 IRE returns a warning, not a failure.
True Peaks Left and right channel input true peak must each be less than or equal to -2.5 dBTP. SVOD, Broadcast Master Greater than -2.5 and less than or equal to -1.5 dBTP returns a close/verify-in-Audition warning. Greater than -1.5 dBTP fails. Missing or -inf measurements return unable-to-measure.
Advanced Chroma For limited-range media, U/Cb and V/Cr values must stay within TV-legal bounds: 8-bit 16-240, 10-bit 64-960, 12-bit 256-3840. SVOD, Broadcast Master Out-of-range Cb or Cr fails. Full-range media marked pc is reported as informational full-range instead of pass/fail.
Caption profanity The first subtitle stream is converted to SRT and must have no matches in the configured profanity word list. Broadcast Master Detected terms fail and produce a Cussbuster report. If no captions are extracted, the result is a warning.
