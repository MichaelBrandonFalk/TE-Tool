Broadcast Master Specification Sheet

Broadcast Master acceptable values and ranges implemented in TE Tool A11. Derived from Resources/script and Resources/Cussbuster2000.py.

Implementation Note

The script declares Broadcast Master targets of ProRes 4444, 200 Mb/s minimum, 29.97 fps, and 16:9 near the top of the file. The current Phase 1 codec and video bit rate functions do not use those variables. They currently enforce ProRes 422 HQ (apch) and 145 Mb/s minimum for Broadcast Master.

Broadcast Master Test Groups

Group Checks Run
Phase 1 File type, video bit rate, video codec, resolution, aspect ratio, frame rate, chroma sampling, scan type, audio codec, audio bit rate, audio sample rate, audio bit depth, timecode format.
Phase 2 Stereo-only audio, loudness, timecode start, marker table, total run time, 608 caption presence, 708 caption presence.
Optional groups I-frame only, caption profanity, Luma IRE, True Peaks, Advanced Luma IRE, Advanced Chroma, Advanced Continuity.

Broadcast Master Phase 1

Field Acceptable Value or Range Failure / Warning Behavior
File type Extension must be exactly mov. Any other extension fails. The check is case-sensitive.
Video codec Currently enforced as codec_tag_string apch, reported as ProRes 422 HQ. Declared Broadcast target is ProRes 4444. Any other codec tag fails under the current implementation.
Video bit rate Currently enforced as greater than or equal to 145000000 bits/s, or 145.0 Mb/s. Declared Broadcast target is 200 Mb/s minimum. Lower, missing, or non-numeric values fail under the current implementation.
Resolution Exactly 1920x1080. Any other width or height fails.
Aspect ratio display_aspect_ratio must be 16:9. If metadata is unavailable, calculated width/height must be greater than 1.76 and less than 1.79. Anything not resolved to 16:9 fails.
Frame rate 29.97 fps. The value is calculated from r_frame_rate and rounded to two decimals. Any other value fails.
Chroma sampling pix_fmt must start with yuv422. Any other pixel format fails.
Video scan type field_order must be progressive or Progressive. Interlaced or unknown scan type fails.
Audio codec codec_name must start with pcm. Any non-PCM audio codec fails.
Audio bit rate Expected bit rate is channels * 1152 Kb/s. Mono is 1152 Kb/s, stereo is 2304 Kb/s. The integer Kb/s value must match exactly. Missing or non-numeric bit rate fails.
Audio sample rate 48000 Hz, reported as 48 kHz. Any other sample rate fails.
Audio bit depth 24-bit PCM. The script checks bit depth metadata, format tags, sample format, and PCM codec name. Any resolved value other than 24 fails.
Timecode format Timecode must exist and contain ; or ,, indicating drop-frame format. Missing timecode or non-drop-frame timecode fails.
Video aspect / position / scale Manual review required. No automated pass/fail is implemented.

Broadcast Master Phase 2

Field Acceptable Value or Range Failure / Warning Behavior
Stereo only Exactly one audio stream and exactly two channels. Any other stream count or channel count fails.
Loudness Integrated loudness from FFmpeg loudnorm input_i must be between -25 and -22 LUFS, inclusive. Outside this range fails. Missing/invalid loudnorm JSON returns an unable-to-test warning.
Timecode start Must start at 00:58:30:00 or 00:58:30;00. Missing or different start timecode fails and asks for Premiere adjustment.
Video markers ExifTool marker start time, name, and duration are read and reported. Informational only; no pass/fail threshold is implemented.
Total run time Total video frame count is converted to 29.97-style drop-frame timecode. Informational only; no acceptable duration range is implemented.
608 captions present At least one subtitle stream codec name must contain eia_608. Missing 608 captions fail.
708 captions present At least one subtitle stream codec name must contain eia_708. Missing 708 captions fail.

Broadcast Master Optional Checks

Field Acceptable Value or Range Failure / Warning Behavior
I-frame only Every video packet must be marked as a key packet, and the first 5000 decoded frames must not include P or B frames. Any non-I packet/frame fails.
Caption profanity The first subtitle stream is converted to SRT and must have no matches in the configured profanity word list. Detected terms fail and produce a Cussbuster report. If no captions are extracted, the result is a warning.
Advanced continuity FPS must be detectable; FFmpeg decode must produce no errors; frame timestamp regressions must be none; timestamp gaps must be none for a clean pass. Decode errors or regressions fail. Gaps greater than 1.5 frame steps warn. Timestamp regression threshold is less than -0.0005 seconds.
Luma IRE Computed IRE must stay from -1 through 101, inclusive. Broadcast Master starts from the first 01:00:00:00 or 01:00:00;00 point if found within the script's search window. Below -1 IRE or above 101 IRE returns a warning, not a failure. Standard Luma samples every 24 frames.
Advanced Luma IRE Same IRE range as standard Luma, but samples every frame. Below -1 IRE or above 101 IRE returns a warning, not a failure.
True Peaks Left and right channel input true peak must each be less than or equal to -2.5 dBTP. Greater than -2.5 and less than or equal to -1.5 dBTP returns a close/verify-in-Audition warning. Greater than -1.5 dBTP fails.
Advanced Chroma For limited-range media, U/Cb and V/Cr values must stay within TV-legal bounds: 8-bit 16-240, 10-bit 64-960, 12-bit 256-3840. Out-of-range Cb or Cr fails. Full-range media marked pc is reported as informational full-range instead of pass/fail.

Luma Code Value Reference

Limited-range black/white code values are 16/235 for 8-bit, 64/940 for 10-bit, and 256/3760 for 12-bit. Full-range black/white values are 0/255, 0/1023, or 0/4095.
